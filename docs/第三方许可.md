## 复核命令

```bash
node scripts/check-licenses.mjs
```

脚本按许可证分组统计，并输出 GPL、AGPL、LGPL、SSPL、EUPL、MPL、EPL、CDDL 或未声明许可证的包及最多 5 条依赖路径。若 `npm ls` 因安装树问题返回非零但仍输出有效 JSON，脚本会继续审计并在末尾列出问题。
