# 国际化（i18n）约定

前端使用 vue-i18n 11（Composition API）。支持 8 种语言，文件名即语言代码：

| 代码 | 语言 | 说明 |
|---|---|---|
| `zh-CN` | 简体中文 | **基准语言**，key 结构以它为准；客户提供的原文（文书规则、打印说明、预约确认语等）中文必须一字不差 |
| `en` | English | |
| `ja` | 日本語 | 本系统用户在日本，日文请用自然的业务用语（例：学生→学生、教室→教室、面谈→面談、文书→書類、出愿→出願） |
| `fr` | Français | |
| `es` | Español | |
| `ru` | Русский | |
| `pt` | Português（巴西） | |
| `de` | Deutsch | |

基础设施已完成，**不要修改**：`web/src/i18n/index.ts`、`web/src/stores/dict.ts`、`web/src/stores/site.ts`、`web/src/App.vue`、`web/src/main.ts`、`web/src/api/http.ts`、`web/src/utils/title.ts`、`web/src/components/LangSwitcher.vue`。

## 文件放哪里

| 内容 | 位置 | 默认导出 |
|---|---|---|
| 公共词条（按钮、菜单分组、布局、登录、个人设置…） | `web/src/i18n/locales/<code>.ts` | `{ common: {...}, menu: {...}, ... }` |
| 模块词条 | `web/src/modules/<模块>/locales/<code>.ts` | `{ <模块名>: { ... } }`，例如 `{ crm: { customer: { title: '我的客户' } } }` |
| 业务字典标签 | `web/src/i18n/dicts/<code>.ts`（**zh-CN 不需要**） | `{ [dictKey]: { [value]: label } }`，dictKey / value 与 `server/src/dict.ts` 完全一致 |

所有文件会被 `import.meta.glob` 自动合并，不需要注册。**每个模块只写自己的 locales 目录**，8 个语言文件的 key 结构必须完全一致（以 zh-CN 为准）。

## 怎么写

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
ElMessage.success(t('crm.customer.saved'))
</script>

<template>
  <el-button>{{ t('common.save') }}</el-button>
  <el-table-column :label="t('crm.customer.name')" />
  <el-input :placeholder="t('crm.customer.searchPlaceholder')" />
</template>
```

- 组件外（`api.ts`、工具函数、store）用 `import { t } from '@/i18n'`。注意：模块顶层常量（如 `const COLUMNS = [{ label: '姓名' }]`）在导入时求值，切换语言不会更新——改成函数或在 `computed` 里调用 `t()`。
- 带变量：`t('common.total', { n: total })`，词条写 `'共 {n} 条'`。
- 词条里的字面字符 `{ } @ | $` 需要转义：`{'@'}`、`{'{'}`。邮箱、价格符号尤其注意。
- 公共词条（`common.save / cancel / delete / edit / search / reset / export / operation / status / remark / all / noData / confirmDelete …`）**直接复用**，不要在模块里重复定义。
- **路由标题 / 菜单**：把 `routes.ts` 中 `meta.title` 改为词条 key，如 `meta: { title: 'crm.menu.customers', ... }`。布局、面包屑、浏览器标题会自动用 `tt()` 翻译。
- **字典**：`DictSelect` / `DictTag` / `useDict().label()` 已自动按语言翻译，页面里不要自己翻译字典值。
- **日期格式**：`fmtDate` / `fmtDateTime` 返回 `YYYY-MM-DD` 这类中立格式，不用改。页面里形如 `'YYYY年M月D日'`、`'MM/DD ddd'` 的格式请改用词条（如 `t('common.dateLong')`）或 dayjs 本地化格式（`'LL'`、`'ll'`）。星期名称用 `dayjs().format('ddd')`，已随语言切换。
- 货币 `money()` 不用改。
- **站点文案**：BrandLogo / AuthShell / Login / PortalLogin / PortalLayout 中的站点名称、副标题、登录标题等，统一用 `site.text('siteName')`、`site.text('loginTitle')`、`site.points()`（管理员未修改的默认文案会自动翻译）。

## 不要翻译的东西

- 后端返回的业务数据（学生姓名、课程名、校区名、通知正文…）。
- 后端返回的错误提示（后端会根据 `Accept-Language` 自己翻译）。
- 代码标识符、权限点 code、字典 value。

## 自检

```bash
cd web && npx vue-tsc --noEmit
cd web && npx vite build --outDir ../../xh-build-check --emptyOutDir
```

完成后在 vite build 通过的前提下删除 `../../xh-build-check`。并运行 `npx tsx scripts/check-i18n.mts <模块名>`（在项目根目录）检查：8 个语言文件 key 是否一致、页面代码是否还残留中文；`npx tsx scripts/check-i18n.mts dicts` 检查字典翻译。
