# 安全说明

记录本系统的安全措施、已知遗留项，以及上线前必须完成的检查。

## 已实施的措施

| 风险 | 措施 | 位置 |
|---|---|---|
| SQL 注入 | 全部数据库访问经 Prisma 参数化查询，代码中没有任何原生 SQL（`$queryRaw` / `$executeRaw`） | 全部模块 |
| 请求参数注入 / 越权写字段 | 所有请求体、查询参数经 Zod 白名单校验，未声明的字段自动丢弃 | `lib/http.ts` `parse()` |
| 存储型 XSS | 通知公告一律存为纯文本（`toPlainText`）；前端渲染先整体转义，再只把 http(s) 网址变为链接（`renderContent`）。自定义站点文案全部用 `{{ }}` 插值，不使用 `v-html` | `service/util.ts`、`web/src/modules/service/api.ts` |
| 密码存储 | bcrypt，成本因子 12；旧的低成本哈希在用户下次登录成功时自动升级 | `lib/password.ts` |
| 弱密码 | 新密码须 8–64 位且同时含字母和数字；使用弱密码登录时后台顶部持续提示修改 | `lib/password.ts`、`AdminLayout.vue` |
| 初始密码 | 学生端初始 / 重置密码为 10 位随机（`crypto.randomInt`，去掉易混淆字符），只在响应中显示一次 | `lib/password.ts` |
| 暴力破解 | 同一账号 15 分钟内失败 5 次锁定 15 分钟；同一 IP 失败 30 次锁定；失败登录写入操作日志 | `lib/rateLimit.ts` |
| 账号枚举 | 账号不存在时也执行一次等时 bcrypt 比对，响应时间与提示一致 | `lib/password.ts` `verifyPassword` |
| 会话失效 | JWT 中带密码版本指纹，修改 / 重置密码后旧 token 立即失效；账号锁定或删除后立即失效；有效期 3 天；固定 HS256 算法 | `plugins/auth.ts` |
| 弱 JWT 密钥 | `NODE_ENV=production` 时若 `JWT_SECRET` 未设置、为默认值或短于 32 位，服务拒绝启动 | `plugins/auth.ts` |
| 上传文件被任意下载 | `/uploads/*` 需登录（HttpOnly + SameSite=Lax Cookie，或 Bearer）；文件名为 128 位随机数 | `app.ts`、`plugins/auth.ts` |
| 伪装文件上传 | 扩展名白名单 + 文件头校验（PDF/JPG/PNG/Office/ZIP）；txt 不得含 NUL 或以 HTML/脚本开头；不允许 SVG/HTML | `lib/upload.ts` |
| 路径穿越 | 静态文件目录禁止列目录与点文件；内部路径解析严格限定在 uploads 目录内 | `app.ts`、`lib/upload.ts` |
| Excel 公式注入 | 所有导出在写出前把以 `= + - @` 开头的文本加 `'` 前缀 | `lib/excel.ts` |
| 点击劫持 / MIME 嗅探 | 全局响应头：`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: same-origin`、`Cross-Origin-Resource-Policy: same-origin` | `app.ts` |
| 跨域 | 默认不开放 CORS（前端同源代理）；需要时用 `CORS_ORIGIN` 显式列出 | `app.ts` |
| IP 伪造绕过限流 | 默认不信任 `X-Forwarded-For`；部署在反向代理后时设置 `TRUST_PROXY=1` | `app.ts` |
| 请求体过大 | JSON 请求体上限 1MB，上传文件 20MB / 单文件 | `app.ts` |
| 依赖漏洞 | `@fastify/jwt` 10、`@fastify/static` 10、zod 4、Prisma 7（驱动适配器）、Vite 8 等全部升级到最新稳定版；exceljs 依赖的 uuid 通过 npm overrides 升到 11.1.1。`npm audit` 结果为 0 个漏洞 | `package.json`、`server/package.json`、`web/package.json` |
| 薪资审核越权 | 审核范围按审核人单独配置（全部 / 本校区 / 自定义校区 + 指定员工），范围条件不可被查询参数覆盖；除超级管理员外不能审核自己的申报 | `service/wage-scope.ts` |
| 越权（IDOR）：客户查重 | 查重只对本人可见范围返回客户详情；范围外只提示「已存在」及负责人 / 校区，不返回姓名和联系方式 | `crm/customers.ts` |
| 越权：客户状态 / 校区 | 「已签约」只能由学员报名写入，手工编辑不能设置或改回；只有全校区范围的人能把客户建到或转到其他校区 | `crm/customers.ts` |
| 越权：班课详情 | 管理者限本校区；普通教师只能看自己任课的班课；学生电话只对管理者返回 | `schedule/routes-base.ts` |
| 越权：面谈 / 面试 | 时间段与记录的查询、发布、修改、删除、代约全部强制校区范围（不可被查询参数覆盖），指定的学员 / 老师也须在本校区 | `service/interviews.ts` |
| 越权：合作机构名单 | 仅客户、报名、学员档案相关岗位可查询 | `common/routes.ts` |
| 匿名可访问的文件 | 只有 `uploads/public/` 下的站点 Logo 可匿名访问（登录页需要）；只有「站点设置」权限可上传，且仅限 PNG/JPG/WebP | `app.ts`、`lib/upload.ts` |
| 自定义文案注入 | 站点名称、登录页文案等全部以纯文本渲染，已实测 `<img onerror>` 只显示为文字 | `site/`、`AuthShell.vue` |
| 安装抢占 / 内网探测 | 首次安装生成高随机安装码，打印到服务器控制台并以受限权限写入 `.install-token`；数据库连接测试和执行安装均须校验安装码 | `install/app.ts` |
| 安装态暴露业务接口 | 未配置数据库时只加载安装应用，其他 `/api/*` 返回未安装；完成后删除安装码文件、关闭安装应用并切换正式应用，正式应用不注册安装接口 | `install/app.ts`、`index.ts` |
| SMTP 密码泄露 | SMTP 密码使用由 `JWT_SECRET` 派生密钥的 AES-256-GCM 加密存储，接口不返回明文 | `lib/mail.ts` |
| 找回密码令牌泄露 / 重放 | 令牌只存 SHA-256 摘要，30 分钟过期且原子标记为一次性；新申请会作废旧令牌，成功重置后旧会话失效 | `auth/routes.ts` |
| 找回密码账号枚举 / 钓鱼链接 | 无论账号或邮箱是否存在均返回相同结果；链接只由管理员配置的系统访问地址生成，不信任请求 Host | `auth/routes.ts`、`lib/mail.ts` |
| 只读（演示 / 审计）账号 | 角色可设为「只读」：持有者除查询外的请求一律被拒绝（统一在登录校验处拦截，不依赖各接口自觉）；只读账号不能改密码，也不能走邮件找回密码；内置角色不能设为只读，最后一个有效的超级管理员不能被加上只读角色 | `plugins/auth.ts`、`system/roles.ts` |
| 演示数据的公开密码 | 安装时导入演示数据后，除安装者设置的管理员外，所有演示教职工账号被锁定并换成随机密码，学生端账号被停用 | `scripts/bootstrap.ts` |
| 越权：跨校区操作 | 数据范围不是「全部」的账号只能修改本校区的课次、班课、VIP 课时包、文书、打印申请和考试；列表里的校区筛选只能在数据范围内收窄，不能越过；没有所属校区的受限账号按「无权」处理 | `plugins/auth.ts`（`campusLimit` / `assertCampus` / `andCampus`）及各模块 |
| 越权：教师借排课取得班级权限 | 只有「编辑本人课次」的教师只能给自己任课的班级排课 | `schedule/routes-sessions.ts` |
| 越权：成绩名单 | 考试关联的班课、追加的学员必须在操作者的数据范围内（教师：本人任课或负责的学员）；只能给名单内的学员录入成绩 | `grades/service.ts`、`grades/routes.ts` |
| 越权：接管管理员账号 | 非超级管理员不能修改超级管理员的资料（含邮箱），避免改邮箱后通过找回密码接管 | `system/users.ts` |
| 越权：客户转学员 | 报名时只能关联自己名下、或有权管理 / 领取的客户 | `students/routes.ts` |
| 越权：学员下拉搜索 | 只返回姓名和学号，并限制在本校区；按电话搜索需要学员查看权限 | `common/routes.ts` |
| 批量操作耗尽资源 | 批量排课日期区间不超过一年；批量发布面谈时间段限制日期数和时段数 | `schedule/routes-sessions.ts`、`service/interviews.ts` |
| 内容安全策略（CSP） | 由后端直接提供页面时（Docker / 单进程部署），页面带 CSP：脚本只允许同源文件，禁止被其他站点嵌入 | `lib/webstatic.ts` |

## 已知遗留项（需评估后处理）

| 项 | 说明 | 当前缓解 |
|---|---|---|
| token 保存在 localStorage | 若出现 XSS 可被读取；已按上表消除已知 XSS 入口 | 3 天过期；修改密码即失效 |
| 上传文件按「已登录」授权 | 登录用户只要知道文件地址就能下载，不做逐文件的业务授权 | 文件名为 128 位随机数，无法猜测或遍历 |
| 合作机构资料共享 | 有「渠道与合作机构管理」权限的人可以查看和修改全部机构（不分校区） | 机构详情里关联的客户 / 学员只列出本人有权查看的 |
| 排课信息跨校区可见 | 有课程表查看权限的人可以查看其他校区的课表和教室占用（协调教室需要），但不能修改 | 修改操作受数据范围限制 |
| 用 Nginx 托管静态文件时没有 CSP | 自行用 Nginx 提供 `web/dist` 时，需要在 Nginx 里自己加 CSP 响应头 | 可参考 `lib/webstatic.ts` 中的策略 |
| 登录限流为进程内存 | 多实例部署时各实例独立计数 | 单实例部署足够；多实例时改用 Redis |

## 上线前检查清单

- [ ] `server/.env` 设置 `NODE_ENV=production` 与 32 位以上随机 `JWT_SECRET`（可用 `node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"` 生成）
- [ ] 根据规模选择 SQLite、MySQL / MariaDB 或 PostgreSQL；外部数据库账号只授予本库所需权限，并设置合理的 `DB_POOL_MAX`
- [ ] **不要运行种子脚本**；用管理员账号创建正式账号后，删除或锁定全部演示账号
- [ ] 全站 HTTPS（反向代理终止 TLS），并设置 `TRUST_PROXY=1`
- [ ] 备份 `uploads/` 目录与数据库（Docker 部署备份整个 `data/` 目录）
- [ ] 数据范围不是「全部」的账号都设置了所属校区；需要跨校区管理的人使用数据范围为「全部」的角色
- [ ] 公开演示时只开放「只读管理员」账号
- [ ] 在「站点设置」中填写正式名称、Logo 与登录页文案
- [ ] 首次安装完成后确认 `.install-token` 已删除，`/api/install/*` 不再可用
- [ ] 如启用找回密码，在「邮件设置」验证 SMTP、发件人和 HTTPS 系统访问地址，确认密码密文存储且测试邮件成功
