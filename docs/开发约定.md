## Schema 规则

- 模型已在 `server/prisma/schema/*.prisma` 定稿。**不要修改已有模型字段。**
- 确实缺字段：在汇报中写明「需要新增字段 X.y，原因…」，由主代理统一加。
- 枚举字段都是 `String`，取值见字段注释与 `server/src/dict.ts`。
- 软删除：有 `deletedAt` 的模型，列表一律过滤 `deletedAt: null`；删除 = 置 `deletedAt`；提供恢复接口的写 `POST /:id/restore`。
- 金额 `Int`（日元/人民币元）；时间 `DateTime`（UTC）；课时 `Float`。
- **不要运行** `prisma db push --force-reset` / `db:reset` / `migrate reset`。数据库已建好并有种子数据。改动 schema 不在你的权限内，所以也不需要 `db push`。

## 后端写法

```ts
import type { FastifyInstance } from 'fastify'
import { z } from 'zod'
import { prisma } from '../../lib/prisma'
import { parse, pageQuery, pageArgs, paged, zIdParam } from '../../lib/http'
import { badRequest, notFound, conflict, forbidden } from '../../lib/errors'
import { perm, staffOnly, studentOnly, staff, student, hasPerm, scopeWhere } from '../../plugins/auth'
import { audit } from '../../lib/audit'

export default async function (app: FastifyInstance) {
  app.get('/customers', { preHandler: perm('crm.customer.view', 'crm.customer.all') }, async (req) => {
    const me = staff(req)
    const q = parse(pageQuery.extend({ q: z.string().optional() }), req.query)
    const where = { deletedAt: null, ...scopeWhere(me, { ownerField: 'ownerId', allPerm: 'crm.customer.all' }) }
    const [items, total] = await Promise.all([
      prisma.customer.findMany({ where, ...pageArgs(q), orderBy: { id: 'desc' } }),
      prisma.customer.count({ where }),
    ])
    return paged(items, total, q)
  })
}
```

- 路由前缀自动为 `/api/<模块目录名>`。REST 风格：`GET /things`（分页）、`GET /things/:id`、`POST /things`、`PUT /things/:id`、`DELETE /things/:id`、动作用 `POST /things/:id/<action>`。
- 校验一律 `parse(zodSchema, req.body|query|params)`；错误一律抛 `lib/errors` 中的函数（中文提示）。
- 权限：路由用 `perm('code', ...)`（任一即可）；学生端接口用 `studentOnly`；细粒度判断用 `hasPerm(req.user, 'code')`。
- 写操作（增删改、确认、审核）调用 `audit(req, action, Entity, id, detail?)`。
- 需要提醒某人时用 `lib/notify.ts` 的 `notifyUser(userId, title, { link })` / `notifyStudent(...)`。
- 多表一致性用 `prisma.$transaction(async (tx) => …)`。
- 时间：业务时区 `lib/time.ts`（`zonedDateTime(date, time)`、`startOfZonedDay`、`isoWeekday`、`dayjs`）。前端提交 ISO 字符串，后端 `z.coerce.date()`。
- Excel 导出用 `exceljs`：`reply.header('Content-Type','application/vnd.openxmlformats-officedocument.spreadsheetml.sheet').header('Content-Disposition', \`attachment; filename*=UTF-8''${encodeURIComponent(name)}\`)` 然后 `return reply.send(await wb.xlsx.writeBuffer())`。
- 上传：前端用 `<FileUpload kind="document|print|image|file">` 先传到 `/api/common/upload`，拿到 `{url,name,size}` 再随业务表单提交。

## 前端写法

- Vue 3 `<script setup lang="ts">` + Element Plus（全局已注册全部组件与图标，中文 locale）。
- 产品名「学航 · 教学管理平台」（站点名称可在后台自定义）。品牌组件 `BrandLogo.vue`。
- **视觉规范**（`web/src/styles/main.css` 已定义，勿改）：浅灰底 + 白色圆角卡片 + 柔和阴影；主色靛蓝 `var(--xh-primary)`，辅色青绿 `var(--xh-teal)`；次要文字 `var(--xh-text-2)`；边框 `var(--xh-border)`。课次类型配色：班课 `--xh-kind-class(-bg)`、VIP `--xh-kind-vip(-bg)`、其他 `--xh-kind-other(-bg)`。不要写死旧的蓝色 `#00a6dd`。
- 页面结构：最外层 `<div class="page">`；需要页内操作按钮时用 `<div class="page-head"><h2>标题</h2><span class="spacer" />按钮…</div>`（顶栏已显示页面标题，纯列表页可省略 page-head）；内容放 `<div class="page-card">`，卡片内小标题 `<h3 class="page-title">`；筛选栏 `<div class="toolbar">`；分页 `<div class="pager">`；数字概览 `<div class="stat-grid"><div class="stat"><div class="stat-label"/><div class="stat-value"/></div></div>`。
- 表格用 `el-table`（不要 `border`，用默认样式），状态用 `DictTag`，主要操作用 `link` 按钮。空状态用 `el-empty`。
- 列表筛选条件同步到 URL query（`router.replace({ query })`），刷新 / 翻页不丢搜索条件。
- 公共组件：`UserSelect`（`identity="TEACHER"` 只列教师）、`StudentSelect`、`RoomSelect`、`CampusSelect`、`DictSelect`（`radio` 模式）、`DictTag`、`FileUpload`、`NotificationBell`。从 `@/components/Xxx.vue` 导入。
- 按钮级权限：`v-if="auth.can('schedule.edit')"`。
- **手机适配**：用 `useIsMobile()`；表格在手机上可改为卡片列表或只保留关键列；对话框宽度用 `useDialogWidth('640px')`；工具栏已在 CSS 中自动换行。
- 时间显示一律用 `utils/time.ts`（东京时区），不要直接 `new Date().toLocaleString()`。
- 不要引入新的 npm 依赖。需要的话在汇报中说明。

## 自检

完成后必须通过：

```bash
cd server && npx tsc --noEmit
cd web && npx vue-tsc --noEmit
```

其他代理在并行开发，若报错只出现在**别人的模块目录**，忽略即可；你自己目录里的错误必须清零。
测接口时用**任务里分配给你的端口**启动自己的后端实例（bash：`cd server && PORT=<端口> npx tsx src/index.ts &`），用完关掉自己启动的进程。**不要动 3001 端口上的服务，也不要杀其他 node 进程。** 演示账号见 `server/prisma/seed.ts` 顶部注释。测试时可以往库里写测试数据，但不要删除种子数据。
