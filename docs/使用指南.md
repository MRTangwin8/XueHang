# 学航 · 使用指南

本文按岗位介绍常见操作，菜单与按钮以中文界面为准。各岗位是工作分工示例，实际菜单由管理员分配的权限决定；看不到按钮或提示无权操作时，应先核对角色、校区、任课关系和数据范围。

[项目首页](../README.md) · [功能与业务规则](功能介绍.md) · [部署指南](部署指南.md)

## 1. 登录与通用操作

1. 教职工打开站点根路径 `/`，使用工号与密码登录；学生打开 `/portal`，使用学号与密码登录。
2. 通过语言切换器选择界面语言；以下步骤均使用中文菜单名称。
3. 在个人设置中修改初始或弱密码，新密码需 8～64 位并同时包含字母、数字。
4. 通过通知铃铛查看待办提醒；处理业务后刷新相应列表核对状态。
5. 列表可按页面提供的校区、姓名、日期等筛选；支持 URL 条件同步的页面在刷新、翻页时保留条件。

本地演示账号见[README](../README.md#演示账号)。正式账号由机构管理员分配，演示密码不适用于新报名学生。

## 2. 系统管理员：首次业务初始化

首次部署且未配置 `DATABASE_URL` 时，后端会进入安装模式。浏览器打开系统地址，输入控制台或 `server/.install-token` 中的安装码，
按“选择数据库 → 站点与校区 → 管理员 → 安装”完成初始化。安装程序会生成安全的 `JWT_SECRET`、保存 `.env` 并切换到正式应用。手动部署方式见[部署指南](部署指南.md)。

### 2.1 校区、教室与科目

1. 打开「系统设置 → 校区管理」，点击「新增校区」。
2. 填代码、校区名称、地址、时区和排序，保存。日本校区通常选择 `Asia/Tokyo`；代码不得重复。
3. 打开「教务管理 → 教室管理」，点击「新建教室」。
4. 选择校区，填教室名称、楼栋、容量、类型，确认是否允许 VIP 使用，保存。
5. 打开「系统设置 → 教授课程」，点击「新增课程」，填写科目名称、分类、排序并启用。此处是教师科目标签；销售产品在「单期课程」「套餐课程」另行维护。

### 2.2 角色与工号

1. 打开「系统设置 → 职务权限」，点击「新建」。
2. 填角色名称，选择本人／本校区／全部数据范围，勾选岗位需要的权限并保存。
3. 打开「系统设置 → 工号账户管理」，新建工号，填姓名、身份、校区、职务角色、初始密码。
4. 教师账号将身份设为教师，并多选教授课程；需要工资申报时补充默认时薪、交通费和银行资料。
5. 按岗位核对菜单。教师身份与职务权限分别配置；仅设置“教师”身份不会自动获得全部教师功能。
6. 为审核人员分配薪资审核权限后，到「人事管理 → 薪资审核范围」设置能审核的校区和员工。

多角色权限合并，数据范围取较宽者。仅向确有需要的人员分配全部权限；系统会保护最后一个有效超级管理员，避免失去管理入口。

### 2.3 产品与站点设置

1. 在「学员管理 → 单期课程」建立可销售课程，再在「套餐课程」维护私塾套餐及其包含课程、价格与 VIP 课时信息。
2. 打开「系统设置 → 站点设置」，填写站点名称、副标题、浏览器标题。
3. 上传 PNG/JPG/WebP Logo，设置主题色、登录标题、宣传标题、宣传要点、页脚和学生端文案。
4. 查看页面预览后保存，检查后台和学生登录页。最多可设置 6 条宣传要点；「恢复默认」会替换自定义设置。
5. 用正式账号完成一次登录与权限检查，再锁定或删除演示工号；演示学生账号也需停用学生端或删除。

### 2.4 账号维护与日志

1. 在「工号账户管理」中搜索账号，通过编辑或更多操作重置密码、锁定、解锁、删除。
2. 误删工号可切换回收站后恢复，原角色和科目关联保留。
3. 在「操作日志」按操作者、动作、对象及时间查询业务操作。日志用于追踪，不提供一键撤销。

### 2.5 业务规则与邮件

1. 打开「系统设置 → 业务规则」，设置客户公海自动回收开关和未跟进天数，按机构规则填写学号、订单号前缀及上传大小上限。
2. 检查页面中的业务下拉选项，修改后用非生产数据验证报名、订单和上传流程。编号前缀只影响新生成记录，不会重写已有编号。
3. 打开「系统设置 → 邮件设置」，填写 SMTP 主机、端口、加密方式、账号、密码、发件人和系统访问地址。
4. 先发送测试邮件；成功后按需开启“站内提醒同时发邮件”。收件人档案必须已有邮箱。
5. 从登录页验证找回密码。重置链接只使用配置的系统访问地址，30 分钟有效且仅可使用一次。

### 2.5.1 行业模板与成绩、档案设置

1. 打开「系统设置 → 成绩与档案设置 → 行业模板」，选择与本机构最接近的模板（日本升学私塾、中国中小学培训机构、语言培训机构、通用培训机构），点击「导入」并勾选要导入的部分。安装向导中已选过模板的，可跳过此步。
2. 在「考试类型」中增减学员档案可录入的考试与证书：设置等级（如 N1～N5）、总分满分、分科成绩及各科满分、总分算法、最多回数、固定考试月份；把常看的科目勾选为「高亮」。已有成绩的考试类型只能隐藏，不能删除。
3. 在「成绩模板」中维护成绩管理新建考试时可选的科目组合（如「初中五科」「雅思模考」）。
4. 在「档案字段」中按机构习惯设置各字段的显示、必填与名称，保存后打开「新学员报名」检查表单。
5. 在「系统设置 → 业务规则」的下拉选项中维护「考试类别」（如月考、期中考试、模拟考试）。
6. 在「职务权限」中给需要的角色分配「成绩管理：查看」或「成绩管理：录入」（新安装时教务、教师、事务已默认分配；从旧版本升级的系统需要手动添加）。

### 2.6 薪资审核范围

1. 先在「系统设置 → 职务权限」给审核人分配薪资审核权限。
2. 打开「人事管理 → 薪资审核范围」，选择审核人，设置全部、本校区、自定义校区或指定员工。
3. 自定义校区与指定员工按并集生效；保存后使用该审核人账号核对「薪资申请管理」可见范围。
4. 查询筛选不会扩大审核范围；除超级管理员外，审核人不能审核自己的申报。

## 3. 教务：排课与教学任务分配

### 3.1 建班与单次排课

1. 在「班课管理」点击「新建班课」，选择校区，填班级名称、科目、默认老师／教室等信息。
2. 打开班级学生名单，加入实际参课学员。报名选择班课方式后仍需完成这一步。
3. 打开「教室预约」「课程表」或「月课表」，选择日期、校区等条件。
4. 点击可操作的空白位置或新建入口，选择班课、VIP 或其他占用，补充关联班级／课时包、老师、教室、起止时间及备注。
5. 查看冲突提示，调整教室、老师或时间后保存；刷新课表核对结果。

冲突检查包括教室、教师和 VIP 学生时间。管理员可显式强制忽略冲突，普通排课应先解决冲突。单节起止跨度不能超过 12 小时。

### 3.2 批量排课

1. 在排课页面或班级相关入口打开批量排课。
2. 选择班课或 VIP 项目、教师、教室，填写起止日期、星期、每日起止时刻；每天重复时选择全部星期。
3. 先点击预览，核对候选日期、冲突、预计生成数量和 VIP 扣用课时。一次最多 200 节。
4. 需要保留其他日期时启用「跳过冲突日期，其余照常生成」；否则先解决冲突再生成。
5. 点击「生成课次」，确认后核对生成数与跳过日期，再到课表查看。

跳过日期不会自动补排。显式「忽略冲突全部生成」需要全部课次编辑权限，会保留重叠安排，使用前需人工核实。

### 3.3 调课与取消

1. 在课表点击目标课次，查看状态、任课教师和关联批次。
2. 待确认课次进入编辑，修改时间、教师、教室等字段；批次课次选择「仅本次」「本次及以后」或「本批全部」。
3. 修改日期时选「仅本次」；批量调整只能修改时刻，不能整体替换日期。
4. 检查冲突后保存。批量范围只包含同批次待确认课次，不包含已确认、已取消课次。
5. 取消时选择相应范围并填写原因，确认后核对课次状态和 VIP 退回课时。

已确认课次通常只能修改备注；删除已确认 VIP 课次或调整其课时数需要专门权限。取消已确认 VIP 课会退回已用课时并记录日志。

### 3.4 VIP 约课与确认

1. 打开「VIP班级管理」，查找学员课时包，核对总课时、已确认、待确认及剩余；需要时由有权限人员建立课时包并分配任课教师。
2. 在课时包详情约课，可单次或批量；填写本次扣用课时，确认剩余足够。
3. 保存后本次课时进入待确认，剩余同步减少；可以继续安排下一节，无需等待上一节确认。
4. 上课后由学生在「我的课时」确认，或由有权限的教务／任课教师在课次详情确认。
5. 未确认课次在下课满 48 小时后由后台定时任务自动确认，通常在下一轮检查时处理；核对账本是否由待确认转为已确认。

结业课时包不能新约课。总课时不能低于已确认与待确认之和；已有未取消课次的课时包不能删除。

### 3.5 出勤管理

1. 打开「教学服务 → 出勤管理」，在「点名」页按日期、班级筛选。
2. 若名单缺人，先通过「班级名单」添加学员；也可粘贴学号／姓名，每行一人，重名使用学号。
3. 打开课次「点名」或「修改点名」，逐人选择出勤、缺席、请假、迟到或早退，填写备注并保存。
4. 在「出勤统计」按学生、班级、课程、日期核对，可导出 Excel，或使用「打印 / PDF」。

统计将迟到、早退计入出勤次数；已开始且未取消的班级课次进入分母，未点名会显示“未记录”。

### 3.5.1 成绩管理

1. 打开「学员管理 → 成绩管理」，点击「新建考试」，选择科目模板，填写名称、类别、日期和校区。
2. 选择「关联班课」会自动带入班级学员；也可以在「追加学员」中添加个别学员。科目可临时增删，或修改满分与及格线。
3. 进入考试详情的「录入成绩」，逐格填写分数，或点击「从 Excel 粘贴」：在 Excel 中按「学号、科目1、科目2…」的顺序选中并复制，粘贴后点「填入表格」，检查无误后保存。分数写「缺考」或勾选「缺考」表示缺考。
4. 班级名单有变化时，点「同步班课名单」补充新学员；单个学员可从表格右侧移出。
5. 在「统计分析」中查看各科均分、及格率、分数段分布与排名；用「导出」生成 Excel 成绩单。
6. 确认无误后点「发布」，学生会收到提醒，并可在学生端「我的成绩」查看。如需更正，可先「撤回」，改好后重新发布。

### 3.6 发布面谈／面试时间段

1. 进入「教学服务 → 面谈预约」或「面试预约」，点击「发布时间段」。
2. 填主持老师、校区、标题、地点／线上信息、日期与自定义起止时刻；可按日期区间及星期生成。
3. 预览可生成与跳过的时间段，检查重叠和过去日期后发布。
4. 学生可自行预约未来可用时间段；需要代约时，点击时间段「代约」，选择学员并确认。
5. 预约完成后通过「写记录」录入指导内容；无记录的预约可由后台在授权范围取消。

每段只接待一人。学生端开始前 8 小时进入取消锁；后台人工取消不受同样时间锁限制，已有记录的预约不可取消。

### 3.7 分配文书

1. 打开「教学服务 → 文书修改」，在「全部」中查找状态为待分配的申请。
2. 查看原文、类型、提交时间与截止时间，点击「分配」，选择批改人员后确定。
3. 分配后对方收到站内提醒，可在「待我批改」处理。
4. 跟踪 7 天返还期限和逾期情况，必要时协调重新分配；已返还申请不能再分配。
5. 管理员误删申请后，可进入回收站点击「恢复」。

## 4. 销售：客户跟进与报名缴费

### 4.1 录入与跟进

1. 打开「客户管理 → 我的客户」，点击「新建客户」，先核对查重结果。
2. 填姓名、联系方式、渠道／合作机构、意向、学科与目标等信息，保存。
3. 打开客户详情，新增跟进，记录沟通方式、内容、到访情况、意向变化和下次跟进时间。
4. 使用「今日待跟进」检查到期客户；在「我的日报」记录当日工作，必要时填入系统统计数。

范围外查重结果只给出有限提示，不表示可以查看对方完整档案。跟进记录只有本人在 24 小时内可删除。

### 4.2 公海领取与交接

1. 进入「公海客户」，搜索待领取客户，打开详情确认情况。
2. 点击「领取」，成功后在「我的客户」继续跟进；已被他人先领取时刷新列表。
3. 将本人客户交回公海时，在「我的客户」勾选后点击「放入公海」。
4. 有全部客户权限的负责人可在「全部客户」选中客户并分配给指定负责人。

若管理员启用了公海自动回收，超过业务规则所设天数未跟进的在手客户会由定时任务退回公海，原负责人收到提醒。销售应及时记录有效跟进，负责人应定期检查回收规则与操作日志。

### 4.3 报名与首笔缴费

1. 从客户详情的报名入口进入，或打开「学员管理 → 新学员报名」。
2. 完成「学员档案」，必填姓名、校区、最终学历、语言学校；担当与签约老师选择教师身份工号。
3. 点击「下一步：项目缴费」，选择私塾套餐、班级分配方式，含 VIP 时填写课时与课程内容。
4. 核对追加课程、币种、优惠与原因、应收；若登记首笔缴费，填写金额、方式等信息。
5. 点击「提交报名」。成功页立即复制或妥善交付学号和初始密码，再查看学员档案。
6. 在「我的在籍学员 → 我销售的」查看套餐及授权的订单信息；后续收款进入学员「选课缴费」或订单详情登记。

客户会随建档标记为已签约，不能手工改写。报名的建档与订单为分步请求：若提示档案已建立、项目缴费失败，应修正后重试或到已有学员档案继续办理，避免重复报名。

## 5. 教师：授课、指导、批改与工资

### 5.1 我的课表与课堂记录

1. 打开「教师中心 → 我的课表」，查看本人课程，点击目标课次。
2. 核对时间、教室、班级或 VIP 学员，填写课堂记录中的授课内容、作业、课堂表现。
3. 按实际需要设置是否对学生可见，保存后再次打开核对。
4. 需要调课时编辑本人待确认课次并检查冲突；非本人课次交由教务处理。
5. 需要确认课次时使用详情中的确认操作；VIP 账本会同步结转。

### 5.2 点名与学生指导

1. 在本人班课详情的点名入口，或「教学服务 → 出勤管理」选择本人课次。
2. 核对班级名单并逐人填写状态、备注，保存。
3. 在「我担当的学生」查看学员档案、考试 / 证书、校内考试成绩与合格信息；有编辑权限时更新档案。有「成绩管理：录入」权限时，可为本人任课班级新建考试并录入成绩（步骤同 3.5.1）。
4. 需要面谈时从学员「面谈」入口进入预约页面，或在面谈／面试页面代约。
5. 会后在关联时间段「写记录」，或进入「面谈&面试记录 → 新建记录」，填写时长、各科情况、志望校与指导建议后保存。

### 5.3 文书批改

1. 打开通知提醒或「教学服务 → 文书修改 → 待我批改」。
2. 下载提交的 TXT 文件，核对学生是否在允许时间内重新上传过，使用最新文件批改。
3. 在截止时间前点击「返还」，上传修改文件，并按需填写修改意见。当前页面要求文件；仅意见返还是接口支持的能力，页面尚不能单独提交。
4. 完成返还后确认状态变为已返还，学生会收到通知。

仅有批改权限时只能处理分配给自己的文书。7 天期限用于跟进服务进度，系统不会自动批改或自动返还。

### 5.4 工资申报

1. 打开「教师中心 → 工资申报」，选择月份。
2. 手工申报时点击「新建申报」，填工作日、起止时间、类别、时长、时薪、交通费、起止站和内容，保存。
3. 如已设置默认时薪，可使用「从课次一键申报」生成当前月份可申报课次的工资记录，核对生成结果。
4. 检查工时、工资金额及交通费。同一次批量按同一天计一次交通费；跨批次需人工检查重复费用。
5. 等待审核；不通过时查看原因，修改后重新进入待审核。已通过的记录不能自行修改或删除。

工资按工时乘时薪四舍五入，交通费另计；关联课次的有效申报不能重复登记。

## 6. 事务：收退款、打印与薪资审核

### 6.1 缴费与退费登记

1. 打开「学员管理 → 订单记录」，按学员或订单查找，进入订单详情。
2. 登记缴费前核对币种、应收和已收，填写金额、方式、日期及凭证等信息后保存。
3. 在「缴费明细」按日期等条件复核，可导出 Excel 对账。
4. 退费时从有权限的订单详情进入，填金额、日期、方式与原因，保存后到「退费记录」核对。
5. 累计退费不得超过已收金额；有缴费的订单不能直接作废。误登缴费只有拥有全部订单权限的人员可在登记当天按规则删除。

以上操作登记业务记录，不执行实际支付或转账。退费后需要教务另行核对课次、课时包和班级安排。

### 6.2 打印处理

1. 打开「教学服务 → 资料打印」，筛选待打印申请。
2. 核对学生、文件名称、黑白／彩色、页数、份数、费用和预计可领取时间。
3. 当前后台列表没有文件下载按钮，需与学生协调取得对应文件后再实际打印。
4. 完成打印后点击「已打印」，学生收到可领取提醒。
5. 领取时核实身份与费用，并按机构流程记录交付。当前页面「已领取」提交状态与接口不一致，尚不能作为可靠的领取登记入口，详见[当前限制](功能介绍.md#资料打印)。

12:00 前提交预计当日 17:00 后领取；12:00 整及之后为次日 17:00 后。实际领取还需确认已完成打印，系统未实现节假日顺延或线上收款。

### 6.3 薪资审核

1. 进入「人事管理 → 薪资申请管理」，确认当前审核范围，选月份、员工、状态等条件筛选。
2. 在「明细」勾选申请，核对工作内容、工时、时薪、交通费及关联课次。
3. 点击「批量通过」或「批量不通过」；不通过时填写原因。
4. 在「按人汇总」核对工资及交通费合计，按需「导出 xlsx」。
5. 若缺少应审核员工，由有工号或职务管理权限的人在「薪资审核范围」配置；筛选条件不能扩大审核范围。

除超级管理员外不能审核自己的工资。审核记录不等同于已完成工资转账。

## 7. 学生：课时确认与服务申请

### 7.1 登录与确认 VIP 课时

1. 打开学生端 `/portal`，输入学号和机构提供的初始密码登录，首次使用后修改密码。
2. 进入「我的课时」，核对各 VIP 课时包的总课时、已确认、待确认和剩余。
3. 查看课次详情；课程开始后，确认实际课次与课时无误，再执行确认。
4. 如安排有误，先联系教务；学生不能在此自行新建或取消 VIP 课次。
5. 下课满 48 小时后仍未确认的课次会由系统后台任务自动确认；确认前后都可查看记录状态及可见课堂内容。

### 7.2 预约面谈／面试

1. 进入「面谈预约」，选择面谈或面试类型。
2. 选择日期与可预约时间段，核对主持老师、时间、地点或线上方式。
3. 点击「预约」，阅读“面谈前8小时将无法取消预约”的确认提示后提交。
4. 在我的预约中核对结果；需要取消时，应在开始前超过 8 小时完成。
5. 已进入取消锁或需要更改安排时联系教务；会后可在页面查看向学生开放的指导记录。

没有时间段时表示当前没有可预约的发布内容，不支持学生任意指定时间。

### 7.3 提交与修改文书

1. 进入「文书修改」，先阅读页面规则，填写标题与文书类型。
2. 上传 TXT 文件，填备注并提交申请。
3. 在申请列表核对状态、锁定时间与返还期限。
4. 首次提交后 24 小时内如需更换，点击「修改（重新上传）」，上传新的 TXT 文件后保存；仅可修改一次，不延长原锁定时间。
5. 返还后查看修改意见并下载返还文件。超过窗口或已返还时不能再改原申请。

### 7.4 提交资料打印

1. 进入「资料打印」，上传 PDF 或 JPG/JPEG。
2. 选择打印方式、份数；PDF 无法识别页数时填写页数，JPG 按 1 页计算。
3. 等待报价，核对页数、费用和可领取时间后提交。
4. 在列表查看进度。尚未打印且状态为待打印时，可取消申请。
5. 收到打印完成通知后，结合预计领取时间到机构领取；费用按机构实际流程支付。

黑白单面 10 日元／张、彩色单面 50 日元／张，总费用为页数 × 份数 × 单价。

### 7.4.0 查看我的课表

1. 在学生端导航进入「我的课表」，顶部显示今日、本周课程数和下一节课。
2. 用「周 / 月」切换视图，左右箭头翻页，「今天」回到本周或本月。班课和一对一课程用不同颜色区分，已取消的课显示删除线。
3. 点击课程查看时间、教室、老师、班级或课时包、本人出勤和课堂记录。上完的一对一课程可在这里直接「确认课时」。
4. 班课由教务安排并加入班级名单后才会显示；如果缺课程，请联系教务确认是否已加入班级。

### 7.4.1 查看我的成绩

1. 在学生端顶部导航进入「我的成绩」。
2. 页面显示考试次数、最近一次成绩与名次、最好得分率和得分率趋势图。
3. 每次考试列出各科分数、平均分和教师评语。只有老师发布后的考试才会显示。

### 7.5 通知与资料

1. 在学生首页查看最新通知，进入通知列表或详情阅读。
2. 通过资料入口进入「资料下载」，搜索并下载向本人校区和学生公开的资料。
3. 文件打不开时先确认仍处于登录状态，重新登录后再试。

## 8. 常见问题

| 问题 | 处理建议 |
|---|---|
| 看不到菜单或按钮 | 让管理员核对权限、角色数据范围、校区与任教关系；教师身份不等于操作权限 |
| 学生密码忘记了 | 由有权限人员在学员详情「更多 → 重置学生端密码」生成新密码；仅展示一次，旧登录失效 |
| 登录失败后暂时不能登录 | 账号或 IP 连续失败会触发限流；停止反复尝试，确认密码并等待锁定期或联系管理员 |
| 剩余 VIP 课时变少但已确认没增加 | 新约课已计入待确认；剩余 = 总课时 − 已确认 − 待确认 |
| 上一节未确认能否继续约课 | 可以，只要课时包在读且剩余足够 |
| 48 小时已到，为什么还未自动确认 | 后台每 10 分钟检查，需保持服务运行；大量积压或任务异常需管理员查看后端日志 |
| 批量排课后缺少部分日期 | 检查星期、预览结果与跳过冲突日期清单；跳过项需另行安排 |
| 批量调课为何不改已确认课 | 批次操作只处理待确认课次，已确认课需按其权限规则单独处理 |
| 出勤率为何低于已点名中的出勤比例 | 分母包括已开始但未点名的班级课次；迟到、早退计入出勤次数 |
| 面谈预约不能取消 | 学生端已到开始前 8 小时锁定点，或预约状态不允许取消；联系教务 |
| 文书上传为什么被拒绝 | 学生文书仅 TXT；还受单文件 20MB、内容校验、24 小时一次修改规则限制 |
| 打印 12:00 提交为何是次日领取 | 当日截止为严格早于 12:00，12:00 整及以后按次日计算 |
| 后台无法标记打印“已领取” | 当前页面与接口状态不一致，先按机构流程人工登记并交开发维护；不要反复提交 |
| 不能审核某位员工或本人薪资 | 检查单独配置的审核范围；普通审核人不能审核自己 |
| 报名失败后却已有学员 | 建档与订单分开提交，保留已有学号，从原页面修正重试或进入已有档案补办订单 |
| 切换语言后通知或课程名没变 | 业务正文和自定义站点文案不自动翻译；部分页面还保留中文 |
| 成绩管理里看不到某次考试 | 数据范围为「本人」时，只显示自己创建或自己任课班级的考试；请管理员检查角色的数据范围 |
| 学生端看不到成绩 | 该考试尚未「发布」，或学生不在本次考试名单中 |
| 档案里没有某种考试 | 管理员在「成绩与档案设置 → 考试类型」中添加或取消隐藏 |
| 手机上列少于电脑 | 小屏会显示卡片或关键列，可进入详情查看；复杂课表建议使用较大屏幕 |

更完整的规则及边界见[功能介绍](功能介绍.md)，上线与备份要求见[安全说明](安全说明.md)。
